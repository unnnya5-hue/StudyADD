# AI駆動開発 体験デモ

選択肢からAIに指示を出すだけで、**要件定義 → 並列実装 → マージ（競合の判断） → テスト仕様書 → 打鍵テスト → バグ修正・回帰テスト**までを体験できるデモサイトです。
題材は「チームTODO」アプリです。

- `index.html` 1ファイルで完結しています（外部ライブラリ・CDN・通信なし）
- 演出は台本どおりの一本道で、選択肢によってAIの返答が少し変わります
- AIが成果物を出すたびに、確認してほしい観点を具体的に並べた「レビュー依頼」を出します（要件・実装・テスト仕様書・修正差分の4回）
- 実装は2体のAIエージェントが並列で行い、マージ時に競合が発生します。どちらの変更が正しいかを要件定義書をもとに人間が判断します（誤った方を選ぶと、AIが要件との食い違いを指摘します）
- 最後に「AI駆動開発 入門まとめ」（役割分担・工程ごとの学び・5つの原則・注意点・始め方）を表示します。印刷・PDF保存して配布資料にも使えます
- 打鍵テストは、完成したアプリをプレビュー上で実際に自動操作して判定しています（初回は2件NGになり、修正後に全件OKになります）

## 開き方

- **ローカル**：`index.html` をダブルクリックして、Chrome または Edge で開くだけで動きます（インターネット接続は不要）
- **URL**：GitHub Pages で公開すれば、URLを共有するだけで開けます（手順は下記）

## 発表用スライド

`slides.html`（公開URL：https://unnnya5-hue.github.io/StudyADD/slides.html ）

- 全13枚：導入 → AI駆動開発とは → デモ → 振り返り（要件定義／並列実装とマージ／テスト）→ 5つの原則 → 注意点 → 始め方 → まとめ
- 5枚目の「▶ デモを開く」でデモサイトを別タブで開けます
- 各スライドに「話すポイント」を付けています（台本ではなく要点メモ）

| 操作 | 内容 |
|---|---|
| → / Space / クリック（右側） | 次のスライド |
| ← / クリック（左側） | 前のスライド |
| `N` | 話すポイントの表示／非表示（スライドの下に出るので、画面共有中は注意） |
| `F` | 全画面 |
| 右上の 🖨 PDF | 全スライドを印刷・PDF保存 |

## 使い方

| 操作 | 内容 |
|---|---|
| `1` / `2` キー、またはクリック | 選択肢を選ぶ |
| `Space` / `→` / ⏭ スキップ | 次の選択肢まで演出を早送り |
| 右上の 1x / 2x / 4x | 演出の速度 |
| ↺ 最初から | リセット |

推奨：PCの Chrome / Edge、横幅1280px以上。プロジェクターで小さく見える場合はブラウザの拡大（Ctrl +）で調整してください。

## GitHub Pages で公開する手順

リポジトリ：https://github.com/unnnya5-hue/StudyADD

1. GitHub のリポジトリ画面 → **Settings → Pages**
2. 「Build and deployment」の Source を **Deploy from a branch** にする
3. Branch で **build-offline-ai-dev**、フォルダは **/ (root)** を選んで Save
4. 1〜2分後に **https://unnnya5-hue.github.io/StudyADD/** で開けるようになります

※ GitHub Pages の公開URLは誰でも閲覧できます（無料プランではリポジトリも Public である必要があります）。社外秘の情報は含めないでください。
