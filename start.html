3準備：ツールを入れる

C コース（チャットだけ）はインストール不要です。6. チャットだけで試すコース へ進んでください。

ターミナル（黒い画面）に、コマンドを貼り付けて実行します。手順は 2026年11月時点の公式ドキュメント（Claude CodeAntigravity）に基づいています。

ターミナルが苦手な人は、画面で操作できる デスクトップアプリ 版でも同じことができます。

ターミナルが苦手な人は、画面で操作できる Antigravity のアプリ 版もあります。このガイドは CLI（ターミナル版）の手順で説明します。

① ターミナルを開く

Spotlight（⌘+Space）で「ターミナル」と入力して開きます。

スタートメニューで「PowerShell」と入力して開きます（管理者として実行する必要はありません）。画面に PS C:\ と表示されていれば PowerShell です。

ターミナルに貼り付けて Enter

ターミナルに貼り付けて Enter

PowerShell に貼り付けて Enter

終わったらターミナルを一度閉じて開き直し、次のコマンドでバージョン番号が出れば成功です。

確認

確認

③ 練習用フォルダを作って起動する

ターミナル

初回はブラウザが開くので、個人のアカウントGoogleアカウントでログインします。フォルダを信頼するか聞かれたら、練習用フォルダであることを確かめてから許可します。

④ 最初の一言を送る

AIに送る
こんにちは。このフォルダは練習用の空のプロジェクトです。これから一緒にTODOアプリを作ります。返答と作る文書は日本語でお願いします。

覚えておく操作

操作内容
EscAIの作業をその場で止める
Shift+Tab（数回）モードの切り替え。画面下に ⏸ plan mode on と出れば Plan mode
/rewind または Esc 2回（入力欄が空のとき）前の状態に巻き戻す（AIが編集したファイルと会話）
/exit終了。claude --continue で続きから再開できる
操作内容
EscAIの作業をその場で止める
Shift+Tab（数回）モードの切り替え（default → accept-edits → auto → plan）。普段は default のまま使う
/plan 指示文そのメッセージだけ Plan mode で送る
/rewind会話を前のメッセージまで巻き戻す。ファイルの変更は戻らないので、こまめにコミットしておく
/usage無料枠の残り（利用量）を確認する
/exit終了。agy --continue で続きから再開できる

default モードでは、AIがファイルを作成・変更する前に変更内容（差分）を見せて許可を求めます。毎回確認できるので、練習にはこのモードが最適です。

4ハンズオン：TODOアプリを作る

C コースは 6. チャットだけで試すコース へ進んでください。

デモと同じ流れです。各ステップで指示文をコピーして送り、レビューのチェックを付けてから次へ進みます。デモと違い、AIの返事は毎回変わります。

💡 各ステップの終わりに「ここまでの変更をコミットして」と頼んでおくと、失敗しても戻せます。

STEP 1要件定義 （デモのフェーズ1）

指示文
チームで使えるシンプルなTODO管理アプリを作りたいです。
【目的】チーム内のタスクの抜け漏れを防ぎたい
【前提・制約】ブラウザだけで動く（サーバーなし）／データは各自のブラウザに保存／タスクに期限を設定したい
【出力】docs/requirements.md に要件定義書を作成。機能要件はID（FR-01〜）付きの表で
不明点があれば、作成する前に質問してください。推測で決めた点は「仮定」と明記してください。

AIから質問が来たら、自分の考えで答えてください。答えに正解はありません。

STEP 2実装計画 Plan mode （デモのフェーズ1の最後）

Shift+Tab を何回か押し、画面下に ⏸ plan mode on と出たら、次の指示を送ります。この間、AIはファイルを変更しません。

指示文の先頭に /plan を付けて送ります（下の指示文には付けてあります）。AIはファイルを読むだけで、実装計画を出して承認を待ちます。

指示文
/plan docs/requirements.md をもとに実装計画を立ててください。
・HTML / CSS / JavaScript だけで作る（ライブラリ不要、index.html をダブルクリックで開ける形）
・作業を2つに分け、サブエージェント2体で並列に実装する前提にする
・並列化の前に決める共通ルール（データの形・一覧の並び順・どのファイルを誰が担当するか）も計画に含める

STEP 3並列実装 SubAgent （デモのフェーズ2・3）

計画を承認したら、次の指示を送ります（Plan mode が解除されていなければ Shift+Tab で戻します）。

計画を承認したら、次の指示を送ります（/plan は付けません）。作業中に /agents と入力すると、動いているサブエージェントの一覧と進み具合を見られます。

指示文
計画どおり実装してください。
最初に共通ルールを docs/conventions.md に書き、それを渡したうえで、サブエージェント2体で並列に作業してください。
終わったら、レビューしてほしい観点（AIが仮定した点・確認してほしい点）を一覧で示してください。

できあがった index.html をブラウザで開いて、実際に触ってみましょう（フォルダを開いてダブルクリック）。

サブエージェントを使うかどうかはAIが判断するため、1体で作業することもあります。その場合も、レビューの観点は同じです。

STEP 4テスト仕様書 （デモのフェーズ4）

指示文
docs/requirements.md をもとに、docs/test-spec.md にテスト仕様書を作成してください。
・正常系と異常系（未入力・空白だけの入力など）を含める
・各ケースに、対応する要件ID・手順・期待結果・「1回目」「2回目」の結果欄を付ける
・対象外にした観点があれば、理由とともに書く

STEP 5打鍵テスト（ここは自分の手で） （デモのフェーズ5）

デモではAIが操作しましたが、ここでは自分でテスト仕様書の手順どおりにブラウザを操作し、結果欄に OK / NG を記入します（記入をAIに頼んでも構いません）。

NGが1件も出なかったら：要件を1つ追加して、STEP 1〜5 をもう一周してみましょう。おすすめは「一覧を期限が近い順に並べ替える」機能です。デモでエージェントBが勝手に入れた改善を、今度は人間が決めた要件として正式に追加します。

STEP 6修正・回帰テスト （デモのフェーズ6）

指示文（○○ の部分を書き換える）
テスト仕様書の TC-○○ がNGでした。
手順：（実際にやった操作）
期待結果：（仕様書の期待結果）
実際の結果：（起きたこと）
原因を調べて修正し、変更差分を見せてください。修正後に再テストすべきケースも教えてください。

🎉 お疲れさまでした！ ここまでで、デモと同じ流れを本物のAIで一通り回せました。

5Skill を作って使い回す Skill

C コースでは使いません。A / B コースで試せます。

ハンズオン中に何度も出てきた「レビュー依頼」を、Skill（AIが必要なときに読み込む手順書）にして、毎回同じ型で出してもらえるようにします。

① Skill のファイルを置く

下の スターターキット から SKILL.md をダウンロードし、練習用フォルダの中の次の場所に置きます（フォルダが無ければ作ります）。

置き場所

ファイルを置くのもAIに頼めます：「.claude/skills.agents/skills/review-request/SKILL.md を作って、次の内容を書いて」と頼み、内容を貼り付けます。

② 呼び出す

Claude Code を一度終了（/exit）して起動し直し、入力欄に次のように入力します。

/skills reload を実行して Skill を読み込み直してから、入力欄に次のように入力します。

入力

7困ったときは

claudeagy --version で「見つからない」「認識されません」と出る

インストール直後は、ターミナルを閉じて開き直すと直ることがほとんどです。直らない場合は公式のトラブルシューティング（Claude CodeAntigravity CLI）を確認してください。

Windows で 'irm' is not recognized と出たら CMD を開いています。PowerShell を開き直してください。

ログインで「このプランでは使えない」と言われる

Claude Code は無料プランでは使えません。B コース（Antigravity CLI）か C コース（チャットだけ）で試してください。

「Gemini CLI」の手順を見つけたけど、そちらではだめ？

個人の無料利用は 2026年6月18日に終了しています。無料で試すなら Antigravity CLI（agy）を使ってください。古い記事の gemini コマンドの手順は、そのままでは使えません。

AIが質問せずに作り始めた／思っていたのと違う方向に進んでいる

Esc で止めて、「いったん止めて。作る前に、不明点を質問してください」と伝えます。大きな作業は Plan mode で計画から始めると防げます。

やり直したい・元に戻したい

/rewind（または入力欄が空のときに Esc 2回）で、指示を送る前の状態に戻せます。ただし、コマンドで変更されたファイルや SubAgent の変更は戻せないことがあるので、区切りごとに「コミットして」と頼んでおくのが安全です。

/rewind で戻せるのは会話だけで、ファイルの変更は戻りません。区切りごとに「ここまでの変更をコミットして」と頼んでおき、戻したいときは「前のコミットの状態に戻して」と頼みます。default モードなら、ファイルを変更する前に差分を見て断ることもできます。

英語で返事が来る

「日本語で答えてください」と伝えます。毎回伝えるのが面倒なら、スターターキットの CLAUDE.mdAGENTS.md をフォルダに置くと、プロジェクトのルールとして読み込まれます。

「利用上限に達しました」と出た

プランごとに一定時間あたりの利用量に上限があります。表示された時間まで待つと再開できます。

無料プランは週ごとに上限が決まっています。/usage で使用量を確認できます。上限に達したら翌週まで待ちましょう。長い会話ほど多く消費するので、ステップごとに新しい会話（/clear）にすると長持ちします。

無料プランは一定時間あたりの回数に上限があります。時間をおくと再開できます。

許可を求められたけど、何をするのか分からない

許可せずに「このコマンドは何をするものですか？」と質問してください。分からないまま許可しないことが、いちばんの安全策です。

練習が終わったら？

練習用フォルダは消して構いません。続けない場合は、プランの更新日までに解約を忘れずに。アンインストール方法は 公式ドキュメント の「Uninstall」にあります。ログイン情報を消すときは /logout を実行します。
